## 3. 清洁模块

### 3.0 视觉参考：分组任务卡片列表模式

> 参考：Donetick (donetick.com) 任务列表页  
> 这是清洁模块"我的任务"和维修模块"工单列表"共用的核心交互模式，先在此定义一次规范，各模块引用。

#### 视觉规范

```
┌───────────────────────────────────────┐
│  🔍 搜索       ⚠️  🏷️  ⏳  ↕️           │
├───────────────────────────────────────┤
│         ─── 2 已逾期 ⌃ ───             │
│  ┌─────────────────────────────────┐  │
│  │[🐾] 逾期12小时  ⟲不定期            │  │
│  │     洗猫碗                       │  │
│  │     [宠物]              (✓大)(⋮) │  │
│  └─────────────────────────────────┘  │
│  ┌─────────────────────────────────┐  │
│  │[🧹] 逾期8天    ⟲每4个月           │  │
│  │     除尘服务器                   │  │
│  │     [清洁]              (✓大)(⋮) │  │
│  └─────────────────────────────────┘  │
│         ─── 1 今天 ⌃ ───              │
│  ┌─────────────────────────────────┐  │
│  │[🗑️] 今天18:00  ⟲每天              │  │
│  │     倒垃圾/回收                  │  │
│  │     [居家]              (✓大)(⋮) │  │
│  └─────────────────────────────────┘  │
│         ─── 1 一周内 ⌃ ───            │
│         ─── 3 更晚 ⌃ ───              │
└───────────────────────────────────────┘
                              (+ 悬浮按钮，左下角/右下角)
```

#### 分组胶囊（时间紧迫度分组头）

| 分组 | 触发条件 | 颜色 |
|------|---------|------|
| 已逾期 | due_date < 今天 | 红/粉色底 |
| 今天 | due_date = 今天 | 橙色底 |
| 一周内 | 今天 < due_date ≤ 今天+7天 | 蓝灰色底 |
| 更晚 | due_date > 今天+7天 | 灰色底 |

- 胶囊居中，左右各接一条分隔线，形如 `─── 2 已逾期 ⌃ ───`
- 胶囊左侧数字=该组任务数，右侧折叠箭头，点击可收起/展开该组
- 组内任务按 due_date 升序排列

#### 任务卡片结构（从左到右）

| 区域 | 内容 | 说明 |
|------|------|------|
| 左侧图标 | 圆形背景 + emoji/icon | 按分类换色，如宠物=粉底、清洁=蓝底、居家=紫底 |
| 卡片顶部 chip 1 | 到期时间文案 | "逾期12小时"/"今天18:00"/"5天后到期"，颜色随分组变化 |
| 卡片顶部 chip 2 | 重复频率 | 带循环图标 ⟲，如"每天"/"每周"/"每4个月"/"不定期" |
| 标题行 | 任务名 | 加粗黑色 |
| 分类标签 | 彩色胶囊 | 如"宠物"/"清洁"/"居家"，用于快速视觉归类 |
| 右侧操作 1 | 大号绿色圆形勾选按钮 | 点击直接完成（免拍照的快速任务）或跳转打卡页（需拍照任务） |
| 右侧操作 2 | 三点菜单 ⋮ | 弹出：跳过、换班、编辑、删除 |

#### 交互细节
- **点击绿色勾选按钮**：
  - 若任务不要求拍照 → 直接标记完成，卡片飞出动画，从列表移除，通知其他成员
  - 若任务要求拍照（如 CoLiv 清洁任务默认需要）→ 跳转打卡页（3.3）
- **点击三点菜单** → 弹出操作面板：
  - 跳过（需说明原因）
  - 请求换班
  - 编辑任务
  - 删除（仅创建人/管理员可见）
- **点击卡片空白处**（非按钮区域） → 展开详情：子任务清单、历史完成记录
- 顶部搜索栏右侧 4 个图标按钮：紧急筛选(⚠️)、分类筛选(🏷️)、逾期筛选(⏳)、排序(↕️)
- 悬浮 **+ 按钮** → 弹出新建任务/新增清洁区域入口

#### "我的任务" Tab 交互
- 严格按 3.0 规范：分组胶囊 + 卡片列表 + 绿色勾选 + 三点菜单
- 分类标签复用清洁区域名（厨房/卫生间/公共区...），颜色按区域预设映射
- **点击绿色勾选按钮** → 因清洁任务默认需要拍照留证，跳转打卡页（3.3），而非直接完成
- **点击三点菜单 → 跳过** → 弹出 Dialog：输入跳过原因 → 确认 → 状态变更为 skipped → 通知下一个轮值人
- **点击三点菜单 → 请求换班** → 见 3.4 换班流程
- 卡片展开态显示子任务勾选清单（灶台/油烟机/地面...）

#### "全部任务" Tab
- 按区域分组展示所有区域当前轮值人
- 可按周/月切换视图
- 点击区域卡片 → 跳转区域详情（轮值历史 + 子任务）

#### "公平看板" Tab

- 偏差 > 30% 显示 ⚠️ 提醒
- 点击成员行 → 展开该成员的清洁历史记录

### 3.2 区域管理 `/cleaning/zones`

- 列表展示所有清洁区域
- **点击区域** → 展开子任务列表 + 轮值顺序设置
- **[+ 新增区域]** → 弹出 Dialog：名称、图标、频率、难度权重
- **轮值顺序设置**：拖拽排序成员 → 保存 → 自动生成下一次排班

### 3.3 打卡页面 `/cleaning/check-in/:assignmentId`

```
┌─────────────────────────────────┐
│  ← 返回        厨房清洁打卡       │
├─────────────────────────────────┤
│                                 │
│  子任务清单                       │
│  ☑ 灶台擦拭                      │
│  ☐ 油烟机清理                    │
│  ☑ 地面拖洗                      │
│                                 │
│  上传照片 (1-3张)                 │
│  ┌──────┐ ┌──────┐ ┌──────┐    │
│  │ 📷    │ │      │ │      │    │
│  └──────┘ └──────┘ └──────┘    │
│                                 │
│  备注 (选填)                      │
│  ┌─────────────────────────────┐│
│  │                             ││
│  └─────────────────────────────┘│
│                                 │
│      [提交打卡]                  │
└─────────────────────────────────┘
```

#### 交互逻辑
1. 用户勾选已完成的子任务
2. 点击拍照区域 → 调用摄像头 → 拍照后预览 → 可重拍
3. 填写备注（选填）
4. **点击[提交打卡]**：
   - 校验：至少上传1张照片
   - 调用 C9 API
   - 成功后：状态变更为 completed → 实时推送给其他成员 → 弹出成功动画
   - 返回清洁中心，该任务移到"已完成"区域
5. 其他成员收到通知："张三完成了厨房清洁，去确认一下？"
   - 点击通知 → 跳转打卡详情 → 可"点赞"确认
   - 超过半数成员确认 → 自动标记为"已确认"

### 3.4 换班流程

1. 在任务卡片上点击"换班" → 弹出成员选择器
2. 选择目标成员 → 填写换班原因 → 提交
3. 目标成员收到通知："张三想把周三的厨房清洁换给你，接受？"
4. **接受** → 排班互换，通知发起人 → 更新待办列表
5. **拒绝** → 通知发起人 → 任务不变

#### 切换"读数模式"
```
  ── 读数模式 ──
  上次读数  [12345        ] (自动填充上次)
  本次读数  [12567        ]
  单价     [0.52         ] 元/度
  ── 自动计算 ──
  用电量: 222 度
  总金额: ¥115.44
  表盘照片  [📷 拍照]
```

#### 交互逻辑
1. 选择费用类型（电费/水费/燃气/宽带/物业/其他）
2. 选择账期（默认当月）
3. 切换录入方式
4. **读数模式**：自动填充上次读数（从数据库取该类型最大 reading_after），输入本次读数，自动计算用量×单价
5. **金额模式**：直接输入总金额
6. 选择分摊方式：
   - **均分** → 自动显示每人金额
   - **按在场天数** → 读取 absent_periods 自动调整比例

7. 拍照表盘（选填）
8. **[确认录入]**：

   - 创建 utility_bill + bill_splits
   - 成功 toast："已录入，每人 ¥106.67"
   - 更新本月账单预览

## 11. 响应式设计断点

| 断点 | 宽度 | 布局变化 |
|------|------|---------|
| mobile | < 640px | 单列，底部 Tab Bar，Sheet 弹出 |
| tablet | 640-1024px | 双列布局（列表+详情），保持 Tab Bar |
| desktop | > 1024px | 三列（侧边栏+列表+详情），顶部导航替代 Tab Bar |

**移动优先策略**：先设计和实现移动端，再扩展到桌面端。合租场景以手机使用为主。
